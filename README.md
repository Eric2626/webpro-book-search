## About

This is my Book Search App from Week 7, deployed for the Week 9 Friday GitHub Pages homework. It is made with HTML, CSS, and JavaScript.

Users can enter a book title or author to search for books. The app uses the Open Library API and shows a cover, title, author, and publication year when available. The page is responsive on desktop and mobile.

## Files

- `index.html` — the homepage and the full Book Search App.

## Deployment

GitHub repository: https://github.com/Eric2626/webpro-book-search

GitHub Pages (after enabling Pages from `main` and `/(root)`): https://eric2626.github.io/webpro-book-search/

To enable GitHub Pages: Repository → Settings → Pages → Deploy from a branch → main → /(root) → Save.

## Test

1. Open the live GitHub Pages link.
2. Search for `Harry Potter` or `Stephen King`.
3. Check that the books appear with titles and authors.
4. Open the site on a phone to confirm the responsive layout.

The Open Library API needs an internet connection and must be available for searches to load.
